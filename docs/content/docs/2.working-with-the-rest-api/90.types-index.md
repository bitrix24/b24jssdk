Every type under [`packages/jssdk/src/types/`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/index.ts) is re-exported from `@bitrix24/b24jssdk`. Only a subset has a dedicated page today; the rest are either documented as part of the class/manager that uses them, or tracked as a follow-up. This table is the map.

## Dedicated pages

| Module | Covers | Page |
| --- | --- | --- |
| `types/common.ts` | scalar aliases, `Fields`, `MultiField`, `UserFieldType`, `DataType` | [Common types](/docs/working-with-the-rest-api/types-common/) |
| `types/payloads.ts` | `PayloadTime`, `GetPayload`, `ListPayload`, `BatchPayload`, `SuccessPayload`, `Payload` | [Payload types](/docs/working-with-the-rest-api/types-payloads/) |
| `types/b24.ts` | `TypeB24`, `ApiVersion` | [TypeB24](/docs/working-with-the-rest-api/types-type-b24/) |
| `core/result.ts` | `IResult` (implemented by `Result` / `AjaxResult`) | [IResult](/docs/working-with-the-rest-api/types-iresult/) |

## Surfaced through another page

## Follow-up (per-domain pages)
